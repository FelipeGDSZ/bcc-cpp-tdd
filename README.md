# Projeto C++ com TDD e Gitflow

Este repositório foi construído para demonstrar práticas de Engenharia de Software, incluindo:
- **Gitflow** para rastreamento de mudanças.
- **TDD (Test-Driven Development)** para garantia de qualidade.
- Automação de build com **Makefile**.

## Estrutura de Diretórios
- `/src`: Código-fonte da aplicação.
- `/include`: Arquivos de cabeçalho (.hpp).
- `/bin`: Executáveis e binários gerados.
- `/test`: Códigos de testes funcionais e unitários.
- `/doc`: Documentação do projeto.
